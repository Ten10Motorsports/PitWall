# Screenshots

Captured from `run-demo.bat` — a synthetic 24-car, two-class race at Spa. No
iRacing was running. This is what you will see when you first start PitWall in
demo mode, before you have touched anything.

| File | What it shows |
|---|---|
| `control.png` | The operator control panel, the page that opens on start |
| `timing.png` | The second-screen timing monitor |
| `tower.png` | The OBS timing tower |
| `tower-class.png` | The same tower grouped by class, with interval and last-lap columns |
| `tower-caution.png` | Under caution: gaps replaced with dashes, not fake numbers |
| `bar.png` | The session bar |
| `card.png` | A driver card, showing driver-submitted profile data |
| `battle.png` | The battle box |
| `map.png` | The self-building track map |
| `results.png` | The full-field standings board |
| `relative.png` `fuel.png` `inputs.png` `hdelta.png` `hflags.png` `hstandings.png` | In-game HUD widgets |
| `hudindex.png` | The HUD widget launcher |
| `signup.png` `register-confirmed.png` | The driver sign-up form and its confirmation |
