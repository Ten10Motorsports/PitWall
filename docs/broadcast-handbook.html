This is the whole job of putting live timing graphics on a race stream. One program on the streaming PC, six browser sources in OBS, and a roster that fills itself in. Nothing to install, nothing to compile, no Python.

This handbook covers
  • Timing tower, session bar, driver cards
  • Battle box, track map, standings board
  • Driver photos, bios and socials on screen
  • Camera and replay control for directing
Deliberately not covered
  • The in-car HUD widgets
  • Per-driver telemetry overlays
  • Anything a driver installs
The one requirement

The program reads live timing straight out of iRacing, so it has to run on a Windows PC that is in the session, spectating or driving. For a broadcast that is almost always the streaming PC itself, with the operator joined as a spectator. If OBS lives on a different machine, that still works over the local network: see OBS on a second PC at the end.

Good news about fullscreen

iRacing can stay in exclusive fullscreen. OBS draws browser sources itself rather than over the game window, so the display mode does not matter for a broadcast. (Windowed mode is only needed for the in-car HUD, which this handbook does not use.)

Part 1

The app

On the PC that will run OBS. About ten minutes, once.

1Download it

One file. No installer.

  1. Open this page: 
    https://github.com/Ten10Motorsports/PitWall/releases/latest
  2. Scroll to the Assets section near the bottom.
  3. Click PitWall.exe to download it. A roughly 9 MB file lands in your Downloads folder.
If the browser objects

Chrome and Edge distrust any .exe that has not been downloaded thousands of times, which a league tool never will be. Click the … next to the blocked download and choose Keep. In Edge it may take two steps: Keep, then Keep anyway.

2Put it in a folder

Not in Downloads. It writes files next to itself.

  1. Open File Explorer and go to your C: drive.
  2. Right-click empty space, choose New then Folder, and name it PitWall.
  3. Drag PitWall.exe from Downloads into C:\PitWall. C:\PitWall contains exactly one file.
Why it matters

The program creates a data folder beside itself for the roster, driver photos and cached track maps. Leave it in Downloads and those end up scattered among your downloads, and a future version overwrites the wrong thing. Put it in its own folder once and every later update is just dropping in a newer .exe.

3First run

Windows will interrupt you exactly once.

  1. Double-click PitWall.exe.
  2. A blue box appears saying Windows protected your PC. Click the small grey More info link.
  3. Click Run anyway. A black window opens and your browser opens the control panel.
Leave the black window open

That window is the program. Minimise it, never close it. Closing it takes every graphic off your stream instantly. Windows only shows the blue warning on the first run of each new version.

The control panel that opened is where everything is configured. Six tabs across the top:

TabWhat you use it for
StatusWhether it is connected, what session, and the addresses to use from other devices.
DiagnosticsTells you why something is not working. Read this first when a graphic is blank.
OverlaysEvery OBS source with its URL, its exact size and a live preview.
RosterDriver profiles. Pull them from the league repo.
LeagueColours and branding, plus where the roster is read from.
Sim controlCamera cuts and replay scrubbing, for directing.

4Rehearse with the demo

Build your entire scene with iRacing closed.

The program can run a synthetic 24-car race at Spa with pit stops, a safety car and a chequered flag. Every graphic behaves exactly as it will on race night. This is how you should do all of the OBS work below.

  1. Close the program if it is running (close the black window).
  2. Open File Explorer to C:\PitWall.
  3. Click into the address bar at the top, type cmd and press Enter. A black window opens, already pointed at C:\PitWall.
  4. Paste this in (right-click pastes in a command window) and press Enter: 
    PitWall.exe --demo --demo-roster --speed 14
Those are double hyphens

The font on this page draws -- as one long dash. It is really two hyphens, three times. Use the Copy button and paste, rather than typing it.

A full race now takes about five minutes. Run it again whenever you want another one. --demo-roster fills in fake driver photos and bios so you can see what the driver card will actually look like.

Part 2

The roster

Driver photos, bios, teams and socials, pulled from the league. Two minutes, once.

5Point it at the league

One URL, pasted once.

iRacing gives a broadcast a name, a number and a team. It gives you nothing else. Everything a viewer actually wants on screen, the headshot, the country, the hometown, the sponsor, the socials, comes from drivers filling in a sign-up form. That collected roster lives in the league repository and this is how the app reads it.

  1. In the control panel, click the League tab.
  2. Scroll down to Roster storage.
  3. Open the Mode dropdown and choose the url option, the one described as a read-only pull from any URL.
  4. In the URL (url mode only) box, paste this: 
    https://raw.githubusercontent.com/Ten10Motorsports/PitWall/main/roster.json
  5. Click Save storage settings. A confirmation line appears under the button.
Read-only on purpose

url mode pulls the roster down and never writes back. That is what you want on a broadcast machine: you cannot accidentally overwrite the league's roster mid-race, and you need no access token to set it up. Drivers manage their own entries through the sign-up form.

6Pull the drivers in

One button. Press it again before every race.

  1. Click the Roster tab.
  2. Scroll to GitHub sync and click Pull from GitHub. The driver list fills in and the count next to the Roster tab updates.

Drivers are matched to cars by iRacing customer ID, not by name. That means an entry survives a name change, and in a team race the card follows whoever is actually in the car at the time.

Add this to your pre-race routine

The roster does not refresh itself. Anyone who signed up since you last pressed Pull from GitHub will show as a bare name and number with no photo. Press it once, every race night, before you go live. It takes a second and it is on the run sheet in step 11.

Nobody has to sign up for the timing to work

This is the question every league asks and the answer is a firm no. Names, car numbers, teams, car, class, iRating and licence all come from iRacing itself, not from the roster. A driver who never touched the sign-up form still appears correctly on the timing tower, the standings board and the timing screen, in the right position with the right gaps.

Signing up adds one thing: the driver card. The headshot, country, hometown, one-line bio, sponsor and socials only exist because a driver typed them in. No sign-up means no card for that driver, and nothing else changes.

So an entry list showing zero drivers is not a fault, and it is not something to fix before a race. It only means no photos yet.

6bSave it as a league

Do this once and race night becomes two clicks.

Steps 5 and 6 pointed the app at one roster. A league profile saves that, plus the colours and the season calendar, under a name. Then choosing a league applies all of it at once, and a broadcaster who covers three different series never retypes a roster URL again.

  1. Click the Leagues tab.
  2. Click New league.
  3. Type the league name, and set the Accent colour to the league's colour. It becomes the highlight on every graphic.
  4. Paste the roster URL from step 5 into Roster URL.
  5. Under Season calendar, click Add a round for each race. Fill in the date and the circuit. Only the circuit is required.
  6. Click Save league. The league appears as a card at the top of the tab.
What race night looks like now

Open the app, open the Leagues tab, click Go live on the right league. That one click sets the colours on every graphic, pulls the roster fresh from GitHub, and puts the round and circuit on the session bar. The card already reads Next up with tonight's round, worked out from the dates in the calendar, so there is nothing to choose.

Changing a track at five to eight

Click Edit on the league that is on air, change the circuit, and click Save league. It applies immediately. Overlays that are already open in OBS follow along without being reloaded, so this is safe to do while you are live.

The same is true of the accent colour and the league name. Anything you can edit here changes on screen within a second, with no scene switch and no browser source refresh.

Where profiles are kept

In data\leagues.json, next to PitWall.exe. Dropping in a newer version of the app keeps them. Copying that one file to another machine gives the co-commentator every league already set up.

Part 3

The OBS scene

Six browser sources, laid out once and saved. About fifteen minutes.

7Add the six sources

Same six clicks each time, with a different name, URL and size.

Start the demo race from step 4 first, so you can see what you are placing. Then, in OBS, for each row of the table below:

  1. In the Sources panel, click +.
  2. Choose Browser.
  3. Type the name from the table, click OK.
  4. Clear the URL box and paste the URL from the table.
  5. Set Width and Height to the size from the table.
  6. Untick Shutdown source when not visible.
  7. Untick Refresh browser when scene becomes active.
  8. Click OK. The graphic appears in the preview with live demo data on it.
Those two tickboxes are the whole ballgame

Leave either one ticked and the source reloads every time you cut to that scene. It reconnects, re-downloads the session, and rebuilds its history from nothing, so for several seconds the tower shows dashes, the track map is blank and the fastest lap is missing. Untick both and the sources stay connected all race, whether they are on screen or not.

Why some are full frame

The driver card, the battle box and the standings board are 1920 × 1080 because they position themselves inside the frame. Give them the full canvas and leave them at position 0,0 with no scaling. Do not crop them to the visible graphic, you will cut off the animation as it slides in.

The tower and the track map are sized to their content, so those you place yourself.

Shortcut

The Overlays tab of the control panel lists all six with a Copy button next to each URL and a live preview on a fake video background. Faster than retyping from this table.

9Build the scenes

Four scenes cover a whole race.

Build the layout above once, then right-click the scene and choose Duplicate for the rest, deleting what each does not need. Sources are shared, so all four stay connected the whole time.

SceneWhat is in itWhen you cut to it
Pre-raceStandings board, session barGrid walk, entry list, the wait before green.
RaceThe full layout from step 8Your home scene. Ninety per cent of the show.
CleanGame capture and session bar onlyA big pass, a crash, anything you want unobstructed.
ResultsStandings board, session barChequered flag, podium, sign-off.
Why a Clean scene earns its place

The moment worth watching is usually the moment your tower is covering. A one-key cut to a bare frame and back is the difference between a stream that feels directed and one that feels cluttered. Bind it to a hotkey in Settings then Hotkeys.

The driver card, and why it is set to auto

The URL in step 7 ends with ?auto=1&hold=8. That means: whenever the camera cuts to a different car, the card for that driver slides in by itself, holds for eight seconds, and slides out. You never touch it.

If you would rather drive it manually, drop ?auto=1&hold=8 from the URL and toggle the source's eye icon instead. The card then shows whichever car the camera is on, permanently, until you hide it.

Directing from the control panel

The Sim control tab cuts cameras and scrubs the replay without alt-tabbing into iRacing. Most exciting jumps to the closest fight on track, and Last incident is how you find the thing you just missed. Replay transport has previous and next incident, slow motion, and a Jump to live button.

10Tune the tower

The main graphic. Configured entirely by its URL.

There is no settings dialog. Every option is a piece of the URL, which means a scene collection carries its own look and you can have two towers configured differently in the same show.

  1. In the control panel, open the Overlays tab.
  2. Scroll to Timing tower option builder.
  3. Change the options. The Live preview below updates as you go.
  4. Click Copy URL.
  5. In OBS, double-click your Timing tower source and paste it over the URL. The tower redraws in the new configuration.

The settings that matter most

OptionValuesWhat it does
rowsa numberHow many cars fit. 16 to 20 for a 1080 frame. Leave it off to show the whole field.
colgap, int, last, best, deltaThe main column. gap is to the leader, int is to the car ahead.
col2sameA second column. col=int&col2=gap is the broadcast standard.
groupclassSplits multiclass fields into class blocks. Essential for GT and prototype races, pointless for a one-make series.
focus1Scrolls the tower to keep the car the camera is on visible. Recommended.
namesshort, surname, full, firstHow names are printed.
scale0.8 to 1.4Overall size. Use this rather than scaling the source in OBS, which blurs the text.
accenta hex colourYour league colour. Write # as %23.

A good starting point for a multiclass league race:

http://localhost:8099/broadcast/tower.html?rows=18&col=int&col2=gap&group=class&focus=1&names=surname
Never scale a browser source in OBS

Dragging a source's corner resamples an already rendered image and the text goes soft, which on a timing tower is the difference between readable and not. Set the source to its real size and use scale in the URL instead, which re-renders the text at the new size.

Practice and qualifying

The same six sources cover the whole night. PitWall reads the session type from the sim and changes what the graphics mean, so you do not build a second scene and you do not reload anything between sessions.

In a raceIn practice or qualifying
Tower orderRunning orderQuickest lap first, no-laps at the back
Tower columnsGap and intervalBest and last, switched automatically
Gap meansDistance to the leaderHow far off the quickest lap
Session barLap 7 / 42A countdown clock
Battle boxClosest fightHidden, there is no fight to show

If you pinned the tower's columns with col= in its URL, that is left alone in every session: you asked for that column and you get it. Leave col= off and the tower decides for itself.

Gaps under caution

When the field is bunched behind a safety car, the gaps between cars mean nothing. Rather than print numbers that are wrong, the tower shows a dash until the race goes green again. That is deliberate, not a fault.

The track map takes a lap

Nothing ships hand-drawn track art, which is why no circuit is ever missing. The map is reconstructed from the position data the sim publishes, so it draws itself during the first clean lap anyone completes and is then cached forever for that track. On a track the machine has raced before it appears instantly.

12When a graphic breaks

Read Diagnostics before you touch anything else.

The Diagnostics tab checks the actual causes and names the one that is biting you, rather than leaving you guessing. Open it first, every time.

What you seeWhat it isFix
Every source blank in OBS The program is not running. Check the black window still exists. Start PitWall.exe again, then right-click each source and choose Refresh.
Graphics load but show no cars Connected to the app, but the app is not seeing the sim. Open Diagnostics. Usually iRacing is not in a session yet, or irsdkEnableMem is off in the sim's app.ini, which Diagnostics will say in plain words.
Drivers have no photos The roster has not been pulled since they signed up. Roster tab, Pull from GitHub. Graphics update live, no OBS restart.
A source goes blank on a scene cut One of the two tickboxes in step 7 is still ticked. Double-click the source and untick Shutdown source when not visible and Refresh browser when scene becomes active.
Back markers freeze or jump The sim is not sending position data for the whole field. On the iRacing website, set Max Cars to 63 and your connection to 1 Mbit or faster. This affects every timing tool, not just this one.
Text looks soft The source has been scaled in OBS. Reset the transform to 100% and use scale in the URL instead.
Gaps show dashes Working as intended, under caution. Nothing. They return at green.
The safe reset

Close the black window, double-click PitWall.exe again, then in OBS right-click each source and choose Refresh. Takes about fifteen seconds and fixes almost everything. Your scenes, sizes and URLs are stored by OBS and are not affected.

Not an OBS source. It is a full timing monitor with sortable columns, sector times coloured purple and green, lap history and lap charts. Open it on a second monitor, a laptop or a tablet. §OBS on a second PC

Only if the sim and the stream are on different machines.

The program has to run on the machine that is in the iRacing session. If OBS is on a different machine on the same network, run the program on the sim PC and point OBS at it across the network.

  1. On the sim PC, start PitWall.exe as usual.
  2. Open the control panel and click the Status tab.
  3. Under Open on this machine or another device, copy the address that starts with http://192.168. or similar. Something like http://192.168.1.20:8099
  4. On the OBS PC, use that address in place of http://localhost:8099 in every source URL.
Example
http://192.168.1.20:8099/broadcast/tower.html?rows=18&col=int&col2=gap
Two things that will bite

The address can change. Home routers hand out addresses that move when a machine reboots. If every source goes blank one week for no reason, re-read the Status tab. Giving the sim PC a fixed address in your router settings makes the problem go away permanently.

Windows Firewall asks once. The first time the program starts, Windows may ask whether to allow it on the network. Tick Private networks and allow it. Refuse, and no other device on your network can reach it.

Both machines, same network

This works over a LAN, not over the internet. A commentator in another city cannot reach it this way. If you need that, the working answer is a tunnel from the sim PC, Cloudflare Tunnel or Tailscale, both free, both giving you a URL that reaches the app from anywhere.

Everything on this page is configured through the control panel at http://localhost:8099/control and through URLs. Nothing is stored in a database, nothing phones home, and the sim is only ever read from, never written to.
