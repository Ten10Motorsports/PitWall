Everything here is generated in the browser from a simulated race, so the drivers, teams and times are invented. Against real telemetry the numbers come from iRacing and the layouts are identical. The one thing this preview cannot show is the self-building track map: on real data it reconstructs the actual circuit from the sim's GPS output, whereas the shape above is a synthetic circuit. To see the graphics on real data, run run-demo.bat for a synthetic race with the full engine, or run.bat with iRacing open.
