HUD widgets

Small transparent always-on-top windows that sit over iRacing while you drive. Each one is a plain URL: add it as an OBS browser source at the size shown, or point a PitWall HUD window at it. Every option is a query-string parameter, so you configure a widget by editing its URL.

Connecting to PitWall…
Options shared by every widget: scale=1.2 to resize the whole thing, opacity=0.8 for panel transparency, accent=%23ff8800 to recolour the highlight, car=N to lock a widget to one car index, and server=http://192.168.1.20:8099 to run the overlay on a second PC. Sizes are for scale 1; multiply by your scale.
