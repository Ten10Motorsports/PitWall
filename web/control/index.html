Widget profiles

A saved layout, referenced from a widget URL as ?profile=name. The engine serves it, so the URL in OBS stays short and a change here reaches every source pointed at it without you touching OBS. Anything written directly into a URL still wins, so a source you have deliberately set up differently is never overruled.

Session

Practice, qualifying and the race can each carry their own columns. Edit the base first, then only the differences on the others. The swap happens on its own when the session changes.

Columns

Drag to reorder. The number beside each one is its width in pixels. The badge says where the figure comes from, which is worth knowing before you call a race on it.
